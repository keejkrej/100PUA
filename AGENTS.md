# 100PUA

Curated prompt lists for courses, papers, and libraries — browse by topic, open individual prompts, copy the query into your AI tool.

Routes: `/` (topic index), `/topic/<slug>`, `/topic/<slug>/prompt/<id>`. Optional features: on-page AI explain and GitHub-backed prompt suggestions.

Topic content lives in `src/data/`; TanStack Start app in `src/`, Effect API/domain in `packages/`. Run `bun run dev` locally, `bun run build` for production.

Maintainer wiring and stack notes: `docs/agent/`.
